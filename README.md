# Mascotte

Библиотека для анимированных псевдо-3D маскотов. Строит фигуры из простых примитивов в pseudo-3D на canvas или SVG и анимирует их.

Проект вдохновлён [Zdog](https://github.com/metafizzy/zdog) от Metafizzy.

## Статус

Ранняя стадия: репозиторий создан, API ещё не определён.

## Планы

- Ядро псевдо-3D рендера (примитивы, проекция, порядок отрисовки)
- Модуль анимации: твины, таймлайны, keyframes, функции плавности
- Примеры готовых маскотов
